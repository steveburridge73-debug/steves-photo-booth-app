Steve's Photo Booth

A personal darkroom for restoring, repairing, editing and playfully transforming photographs.

This page is the site root

GitHub Pages was returning 404 because the repository had no index.html in the root. The application source was already here, in src, public and scripts — not inside another project folder.

Those folders have to stay. The workshop is a server application: generating and editing a photograph calls an API that GitHub Pages cannot run. Moving every file into this one folder would also overwrite shared names such as index.tsx.

What lives in the repository

  • src — screens, tools and prompts
  • public — icon and share image
